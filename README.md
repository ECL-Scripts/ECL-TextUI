# ECL-TextUI

Modern and minimal TextUI system for FiveM built with smooth animations, optimized performance and premium UI design.

━━━━━━━━━━━━━━━━━━━━━━

## Features

• Modern dark UI
• Smooth animations
• Optimized performance
• Lightweight design
• Easy integration
• Standalone support
• Clean ecosystem styling
• ESX / QBCore / ox_core compatibility

## Installation

Add the resource to your `resources` folder and ensure it in your `server.cfg`.

```cfg id="jlwmes"
ensure ECL-TextUI
```

━━━━━━━━━━━━━━━━━━━━━━

## Export Examples

### Show TextUI

```lua
exports['ECL-TextUI']:Show({

    key = 'E',

    text = 'Example'

})
```

### Hide TextUI

```lua
exports['ECL-TextUI']:Hide()
```
