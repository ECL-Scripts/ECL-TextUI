• Modern dark UI

• Lightweight design

## Installation

Add the resource to your `resources` folder and ensure it in your `server.cfg`.

```cfg id="jlwmes"
ensure ECL-TextUI
```

━━━━━━━━━━━━━━━━━━━━━━

## Export Examples

### Show TextUI

```lua
exports['ECL-TextUI']:Show({

    key = 'E',

    text = 'Example'

})
```

### Hide TextUI

```lua
exports['ECL-TextUI']:Hide()
```
